# Інструкції для агента (Claude Code) — пошук тем, розслідування, сценарії

Цей репозиторій — робоча станція для YouTube-каналів **Revela** (розслідування будь-яких новин і подій) і **Lume**
(«звичайна людина легально б'є гіганта»). Агент шукає хайпові теми, перевіряє гіпотези цифрами, збирає досьє
і пише сценарії. Відповідай українською, назви відео й цитати — англійською.

## Команди

```bash
pip install -r requirements.txt
python -m niche_finder radar                         # радар хайпу: нові теми + перевірка вже запропонованих
python -m niche_finder radar --no-rising             # без зростаючих запитів Google Trends (якщо 429)
python -m niche_finder discover                      # формати, які клонують малі канали
python -m niche_finder formats @канал --exclude "Lume,TrueCrimeVault,ago,Lumicus"
python -m niche_finder viral @канал                  # outlier-відео каналу → формули
python -m pytest -q                                  # тести
```

Звіти падають у `reports/`. Досьє й пакети — у `research/<тема>/`.

## Принцип 1. Тема = гіпотеза, яку перевіряють цифрами

Тема потрапляє в роботу, лише якщо її підтверджують **3 з 4** незалежних сигналів:

| Сигнал | Де | Що означає «так» |
|---|---|---|
| Попит | Вікіпедія (pageviews), Google Trends | ріст ×1.5+ до медіани 14 днів або 20K+ переглядів/добу |
| Кросплатформність | Google News, Reddit (r/all + тематичні), X (getdaytrends), Threads* | тема одночасно на 2+ платформах |
| Пошукова намірність | автодоповнення Google / YouTube / Amazon | YouTube підказує «… documentary / what happened / explained» |
| Прогалина | YouTube за тиждень/місяць | мало довгих (≥10–15 хв) відео або вони слабкі |

\* Threads — лише з `THREADS_ACCESS_TOKEN` або Apify.

Фаза теми: **розгін** (ранній вхід, найкраще) → **росте зараз** (робити за 1–3 дні) → **після піку** (лише з новим приводом).
Кожна теза у звіті має посилання для ручної перевірки (графік Вікіпедії, Google Trends 7 днів, YouTube за тиждень, Google News).

## Принцип 2. Ловити до хайпу

- Щодня `radar`: дивитися фазу «розгін» з ще малими цифрами і статті-«новачки» в топ-1000 Вікіпедії.
- Зростаючі запити Google Trends (Breakout = +5000%) по базових словах у 4 країнах.
- r/OutOfTheLoop — люди питають «що відбувається» до піку.
- Календар на 1–3 тижні: релізи документалок/фільмів про реальні справи, дати судів, вироків, страт, річниці.

## Принцип 3. Факти

1. Жодного факту без джерела. Джерело — сторінка, яку **реально відкрили**; зведення пошуковика — не джерело.
2. 2+ незалежні відкриті джерела = підтверджено; 1 = писати з атрибуцією («according to…»).
3. Розбіжності між джерелами — окремим списком; у сценарії подавати як розбіжність.
4. Підозрюваних без вироку не називати винними: «allegedly», «arrested, not charged». Не називати ім'я, якщо влада його не оприлюднила.
5. Жертви — з повагою; графічні деталі злочину позначати «не для озвучки».
6. Українські й російські видання — не джерела (правило каналу), окрім випадків, коли власник явно просить і подання з атрибуцією.
7. Мережеві фейки розбирати окремим блоком: хто запустив, як поширилось, хто спростував.

## Принцип 4. Конвеєр теми (як працювали агенти)

1. **Радар** → кандидати з балом і посиланнями.
2. **Досьє** — 2 агенти паралельно:
   - агент А «людина і справа»: біографія, хронологія від початку до кінця, ніч події по хвилинах, люди, цитати, реакції, суперечності, джерела;
   - агент Б «система й відео»: як влаштована система/процедура, прецеденти, експерти, усі відео (60+), транскрипти, таблиця вставок з таймкодами, конкуренти.
   Шаблони промптів — `prompts/`.
3. **Конкуренти** — транскрипти 5–12 найкращих розборів жанру: холодні відкриття дослівно, % хронометражу, де вставки, як подають невизначеність.
4. **Сценарій** — версія з ведучим (`[HOST]` / `[VO]`) + шот-лист (`[3D]`, `[АРХІВ: URL @ таймкод]`, `[ГРАФІКА]`, `[ЗВУК]`), 10–12 хв, ~150–160 слів/хв.
5. **Пакет** — `INDEX.html` (досьє, сценарій, відео з прев'ю, джерела) + ZIP.

## Принцип 5. Сценарій (шаблон 10–12 хв)

| Блок | % | Що |
|---|---|---|
| Хук | 7 | найгірший момент у теперішньому часі + цифра в перші 20 с + «So how…?» |
| Що відомо / ні | 5 | рамка невизначеності (Mentour-стиль) |
| Звичайний старт | 9 | люди, «рушниці Чехова» (деталь, що спрацює пізніше) |
| Механіка | 7 | одна річ, яку треба зрозуміти (двері кабіни, протокол, закон) |
| Подія | 20 | хвилина за хвилиною, короткі речення, джерела в тексті |
| Перелом / порятунок | 15 | емоційний пік; повтор хука кожні 2–3 хв |
| Наслідки | 10 | архів, заяви |
| Хто і чому + фейки | 12 | версії без вердикту, прецеденти |
| Система | 10 | ширша проблема, пропорція («рідкісно, але…») |
| Фінал | 5 | рима до хука + питання в коментарі |

Насильство — звук і реакція, без графіки; не вставляти кадри з кров'ю. Спонсор — лише після кліфгенгера, далі рекап.

## Принцип 6. Формати й переноси

- Береться **концепт** аутлаєра, не його тема.
- Формат множиться по осях: ніша, персона, мова (іспанська/португальська — найчастіше вільні), кут.
- Переноси перевіряються `formats` (вільно / тісно / завалено клонами); власні канали виключати (`--exclude`).

## Технічні нотатки

- YouTube: метадані й пошук — yt-dlp (без ключа). Транскрипти з хмарних IP часто блокуються («not a bot») — локально:
  `yt-dlp --cookies-from-browser chrome --skip-download --write-auto-subs --sub-langs "en.*" <url>`.
- Google Trends зростаючі запити (pytrends) швидко дають 429 → резидентні проксі в `PROXY_URLS`.
- Вікіпедія per-article API ріже частоту → радар бере ряди з денних топ-1000 і робить повні запити лише для топ-20.
- Ключі й паролі — тільки в `.env`, ніколи в коміти й чати.
