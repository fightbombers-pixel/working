# Агент — сценарій з ведучим

Вхід: DOSSIER.md + SYSTEM_AND_VIDEOS.md + розбір конкурентів. Канал: <Revela/Lume>. Хронометраж 10–12 хв (~150–160 слів/хв).
Форма: [HOST] — ведучий у кадрі, [VO] — голос поверх кадрів; під кожним блоком шот-лист:
[3D: кадр], [АРХІВ: URL @ таймкод], [ГРАФІКА: …], [ЗВУК: …], (пауза).
Структура — шаблон із CLAUDE.md (Принцип 5). Лише факти з досьє, з атрибуцією; підозрюваних без вироку не називати
винними; без графічного насильства; розбіжності й фейки — окремим блоком; фінал римується з хуком.
Наприкінці — чек-лист «звірити перед записом» і підрахунок слів по блоках.
